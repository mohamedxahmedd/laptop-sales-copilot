# V4.3.1

- Strong gaming requests no longer force a 24GB RAM target.
- Recommendation ordering now uses total match score first, preventing a weaker workstation GPU from winning purely because it ticked a binary "meets needs" flag.
- Gaming GeForce suitability modifier remains active.
- Named FC titles (e.g. FC27) are surfaced to the sales-copy prompt so the reply can mention the exact game naturally without making unverified FPS/performance guarantees.
- Exact GPU-only sales messages lead with the GPU benefit instead of generic CPU/RAM copy.
